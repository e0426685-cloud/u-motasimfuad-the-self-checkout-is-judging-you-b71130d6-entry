A one-line comedy entry for the [The Self-Checkout Is Judging You](https://make.fun/competitions/u-motasimfuad-the-self-checkout-is-judging-you-b71130d6) bounty on make.fun: a single funny remark in the voice of a smug self-checkout machine, judging a shopper whose entire basket is twelve yoghurts and nothing else.

> Twelve yogurts and zero actual food — don't worry, I'll ring it up as groceries so you can keep calling it a meal plan.

## How it works

`main.py` (Python standard library only) holds the entry line, checks it is a single non-empty line within the 200-character limit, and writes it to `/output/entry.txt` with a plain `open()` call, setting the file mode to `0644` so the grader can read it.
